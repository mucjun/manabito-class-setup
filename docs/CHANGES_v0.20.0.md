# v0.20.0（2026-11-23）先生の PC の講習後の片付け

淳さんの要望：先生用の窓から、先生の PC（複数の講師が同じローカル ユーザーで使う）を次の講習に備えて片付ける。
淳さんの選択：ブラウザーは初めの状態に戻す・移したファイルは消さない（手で整理する）・追加のおすすめ（画面・音・プリンター／Bluetooth・Wi-Fi・クリップボード・
スクリーンショット／先生用の窓の状態／保存していないファイルがあれば止める）をすべて入れる。

- 先生用の窓の左下に［講習後の片付け（この PC）］［教室の基準を覚え直す］。片付けは本体の窓が行う（share::kTeacherCleanupMsg）。
- scripts\teacher_cleanup.ps1・scripts\modules\teacher.ps1（管理者）：ファイルを移す → ［履歴を消す］（Invoke-CleanAll に飛ばす項目を指定できるようにした）→
  画面・音・プリンター・クリップボード・Wi-Fi。
- 本体（C++）：開いているアプリの確かめ、Bluetooth（BluetoothRemoveDevice。基準に無いもの）、先生用の窓の状態を空にする（share::ResetTeacherWork）、まとめの知らせ。
- ビルドに Bthprops.lib。

## 自分でのレビューで直したこと

- 移したあとに［履歴を消す］が動くと、移しきれなかったダウンロード・デスクトップのファイルを消してしまう → 先生の片付けでは、その 3 項目を飛ばす。
- 保管のフォルダー名が分までで、1 分以内に 2 回片付けるとぶつかる → 秒まで。
- Wi-Fi の名前に空白があると、PowerShell 5.1 が netsh への引数を崩す → 渡す文字をそのまま組み立てる。
- Bluetooth・Wi-Fi は、機器の種類で判断すると教室の機器まで消すおそれ → 「教室の基準」を覚えて、それに無いものだけを消す。

## 確かめたこと（この検証環境）

- ファイルを移す：ショートカットと desktop.ini は残る、講習の保管自身は移さない、前回の保管は混ざらない。
- Wi-Fi：初回は基準を覚えるだけ、2 回目は基準に無いもの（空白を含む名前も）を消す、今つないでいるものは消さない。
- MinGW のビルド（警告なし）。

## 実機で確かめること

- 開いているアプリがあると止まるか。ファイルが「ドキュメント\講習の保管」に移るか。
- サインアウトのあと、NAS につながるか（資格情報が残っているか）。
- 画面の「複製」、音の出口（PC のスピーカー）、既定のプリンター、クリップボードの履歴（Win＋V）が戻るか・消えるか。
- Bluetooth と Wi-Fi：1 回目は基準を覚えるだけ、2 回目に講師のスマホなどが外れるか（教室のマウスなどは残るか）。
