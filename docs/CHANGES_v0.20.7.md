# v0.20.7（2026-11-23）除外のバッチを Program Files にも入れる・マニュアル

- Program Files に入れるとき（install.ps1）、defender_exclude_add.cmd・defender_exclude_remove.cmd も入れた先にコピーする。
  ダウンロード・デスクトップ・ドキュメントで展開した ZIP から入れると元の展開フォルダーを消すため、入れたあとにバッチが無くなっていた。
  これからは C:\Program Files\Org_Apps\ManabitoClassSetup から実行できる（更新のたびに新しいものに入れ替わる）。
- docs\まなびと講習準備_マニュアル.docx（事務員向けの使い方。Windows セキュリティの対策を含む）。
