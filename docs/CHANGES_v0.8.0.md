# v0.8.0（2026-11-20）ブラウザーの履歴・閉じるときの自動削除

淳さんの要望。

- ［履歴を消す］に Edge・Chrome を追加：お気に入り、履歴、Cookie・サイトのデータ、キャッシュ、開いていたタブの記録。
  保存されたパスワードと自動入力も消す（Claude の提案。プロファイルの browserClearPasswords を false にすると残す）。
  ブラウザーは強制的に閉じる。Edge が裏で起動し直したときは、もう一度閉じて残りを消す。
  プロファイル（Default・Profile n・Guest Profile）ごとに消す。設定・拡張機能・内部用のプロファイルは残す。
- 点検に「Edge／Chrome のお気に入り・履歴・Cookie」を追加（お気に入りの件数、履歴・Cookie・パスワードの記録の有無）。
- アプリを閉じるとき「作業でできた履歴を削除します」→［履歴を消して閉じる］（初期）／［消さずに閉じる］／［キャンセル］。
  消すときは確認なしに［履歴を消す］を行い、終わったら閉じる。プロファイルの cleanOnExit で有効・無効（標準は有効）。
- 検証：Edge と同じ形のフォルダーで、点検（お気に入り 4 件・入れ子のフォルダーを含む）→ 消す（7 件）→ 点検（そろっている）を確認。
