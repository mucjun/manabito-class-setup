# v0.12.1（2026-11-20）受信 2 GB を超えると止まる不具合

淳さんの試験（まとめて実行、Office のインストール）：受信 1.98 GB の次、2.17 GB になった時点で
「"Max" の引数 "val2" (値 "2170142105") を型 "System.Int32" に変換できません」で失敗。

- 原因：[Math]::Max(0, 受信量) のように整数の 0 を書いていたため、Windows PowerShell 5.1 が Int32 の計算を選び、2^31（約 2.1 GB）を超えて失敗。
  PowerShell 7（検証環境）では起きないため、これまでの試験で見つけられなかった。
- 直したこと：
  - 受信量・速さ・割合の計算を double で行う（[double]0 など）。
  - 進み具合の表示の計算でエラーが起きても、インストーラーの見張りは続ける（表示のエラーで作業を見失わない）。
    今回は見張りだけが止まり、Office のインストールは裏で続いていたと考えられる。
  - Get-RegValue を、値が無くてもエラーを出さない読み方に変更（記録に「終了エラー(Get-ItemProperty)」が並んでいた）。
- 検証：受信を 2 秒ごとに 700 MB 増やす試験で、4.1 GB まで止まらず「99%・仕上げ中」で終わることを確認。

## うまくいったこと（同じ記録から）

- Program Files からの起動（v0.11.0 の自分自身のインストール）。
- Office の展開ツールの署名の確認（Valid）。
- 進み具合の表示（約 199 Mbps、残り時間）。まとめて実行は Office の失敗のあとも履歴の削除まで進んだ。
