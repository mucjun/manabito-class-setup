# v0.18.0（2026-11-21）登録済みの PC に自動で配る

淳さんの要望（受講生は 15 名まで）。共有フォルダーで押し込む案は、受講生の PC に入口を開く・アカウントが要る・不安定などの理由で採らず、
「報告の返事で知らせ、受講生の PC が自分から取りに行く」形にした。

- 先生用［配る］タブに［登録済みの PC に自動で配る］／［自動で配るのをやめる］と、受け取り済みの台数。
- 先生の PC：ファイルごとの SHA-256 を裏で計算（計算の途中で大きさが変わったら止める）、一覧に署名。5,000 個・20 GB まで。
- 受け渡し：報告の返事に配る番号。PUSHMAN（一覧と署名）、PUSH|番号|PC名 のあと PGET|i（中身）、DONE。
- 受講生の PC：署名と SHA-256 の確かめ、受け取るフォルダーの外を指す名前の拒否、空き容量の確かめ、一時的な名前で受け取ってから置き換え、
  同じものは受け取らない、失敗は 3 回までやり直し、受け取ったら知らせる（フォルダーを開くか聞く）、結果を報告に入れる。
- tests\crypto_test.cpp に、ファイルの SHA-256（"abc" の値）と一覧の署名の試験を追加。

## 自分でのコードレビュー

- ［自動で配るのをやめる］で、ロックを持ったままボタンの文字を書き換えていた → ロックを離してから。
- ロックの中での送受信・待ち・画面の操作を機械的に洗い出し、0 件を確認。配っているものの記録は、裏の処理からはロックの中だけで読む。
- 大きさが一覧と違う中身が届いたとき、つながりを保てない（本文が続く）ため、その時点で受け取りをやめる。
