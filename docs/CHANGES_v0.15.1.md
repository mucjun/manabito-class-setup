# v0.15.1（2026-11-21）実機の試験を受けて

淳さんの実機の試験（v0.15.0、Windows 11 Pro 26H2 ビルド 26300 など複数台）から。

- Office の LAN 配布は成功：配布サーバー（DESKTOP-DN459OD）から 3.77 GB を 4 分 11 秒で受け取り、インストール 3 分 32 秒（インターネットの受信 25 MB）。
- 更新の確認は正しく「新しい版なし」（全台 0.15.0 のため、インターネットからの更新はまだ未確認）。

## 直したこと

- **タスクバーのウィジェット**：26H2 では管理者のポリシー（Dsh\AllowNewsAndInterests）の書き込みも「許可されていない操作」で止められた。
  淳さんの提案どおり、標準・WEB 講座のプロファイルでは「確認のみ」（点検で表示するだけ）にした。「出さない」にしたプロファイルでも、止められたら失敗にせず手で消す方法を案内。
- **保存されたログイン情報**：資格情報の関数（CredEnumerate）をスクリプトから直接呼ぶのをやめ、Windows の cmdkey（/list・/delete）に変更。
  パスワードを盗むウイルスと似た動きのため、ウイルス対策に疑われるおそれがあった（1 台でトロイの木馬として削除された件の有力な原因）。実機でも「調べられません」だった。
  日本語・英語の表示の両方に対応。「ドメイン パスワード」（ネットワーク共有・プリンター）は残す。
- **スタートの「最近使用」**：
  - ［設定をそろえる］に「スタートの『最近使用』を出さない」を追加（Start_TrackDocs・Start_IrisRecommendations = 0。プロファイル startRecent、標準は hide）。点検にも追加。
  - ［履歴を消す］で、最近使ったファイルを消したあとスタートメニュー（StartMenuExperienceHost）を読み込み直させる。
