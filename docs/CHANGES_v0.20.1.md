# v0.20.1（2026-11-23）デスクトップのショートカットを置かない・スタートの一覧に出さない

淳さんの要望：受講生に安易に触らせたくない。

- このアプリ（Program Files に入れるとき・更新のとき）と独自アプリは、デスクトップにショートカットを置かない。スタートメニューの「まなびとツール」だけに置く。
  前の版がデスクトップに置いた、このアプリを指すショートカットは片付ける（目録の shortcut の指定は使わない）。
- ［設定をそろえる］と点検に「スタートの『最近追加したアプリ』『よく使うアプリ』」（プロファイル startAppsList、標準 hide）：
  HKLM\SOFTWARE\Policies\Microsoft\Windows\Explorer の HideRecentlyAddedApps=1、HKCU の Explorer\Advanced の Start_TrackProgs=0。
  特定のアプリだけを「最近追加」から外す設定は Windows に無いため、一覧そのものを出さない。
- 確かめたこと（この検証環境）：何も無い→「出す（2 か所）」、そろえた→ OK。MinGW のビルド（警告なし）。

## 実機で確かめること

- 更新のあと、デスクトップの「まなびと講習準備」が消え、スタートの「すべて」→「まなびとツール」に残るか。
- ［設定をそろえる］のあと、スタートの「最近追加したアプリ」「よく使うアプリ」（おすすめ）に、このアプリとまなびとバックアップが出ないか。
