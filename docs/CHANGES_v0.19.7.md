# v0.19.7（2026-11-23）エクスプローラーのよく使うフォルダーを消す

淳さんの要望：エクスプローラーのクイック アクセスと左の一覧に、前の受講生が開いた NAS のフォルダー（よく使うフォルダー）が残る。

## 原因

よく使うフォルダーは、クイック アクセスのピン留めと同じファイル（f01b4d95cf55d32a.automaticDestinations-ms）に記録される。
［履歴を消す］はピン留めを守るためにこのファイルに触れていなかったので、よく使うフォルダーも残っていた。

## 加えたもの

- 点検「エクスプローラーのよく使うフォルダー（クイック アクセス）」：ピン留めでない項目の件数。ピン留めかは System.Home.IsPinned で見分ける。
- ［履歴を消す］：ピン留めでない項目だけを removefromhome（「クイック アクセスから削除」）で消す。ピン留めは残す。
  残ったときの予備：ピン留めが Windows の初めの 6 つだけなら、エクスプローラーを止めて記録のファイルを消し、起動し直す（初めの 6 つに戻る）。
  初めのものでないピン留め（先生の NAS など）があるときは、ファイルを消さずに、手で消す方法を案内する。
  ピン留めの印を読めない Windows では何もしない（ピン留めを消す事故を防ぐ）。
- ［設定をそろえる］「エクスプローラーの『よく使うフォルダー』『最近使ったファイル』の表示」：ShowFrequent=0・ShowRecent=0（プロファイル quickAccessHistory、標準 hide）。
- tools\release.ps1：この部品自身だけの変更は「残っている変更」に数えない（初めて置いたときに止まらないように）。

## 確かめたこと（この検証環境。エクスプローラーの代わりを作って）

- 全部消えた → DONE、残った・先生のピン留めあり → ファイルを消さずに FAIL と案内、印を読めない → SKIP、0 件 → SAME。

## 実機で確かめること

- 点検の件数が、写真のクイック アクセス（よく使うフォルダー）と合うか。［履歴を消す］で消え、ピン留め（デスクトップなど）が残るか。
- ［設定をそろえる］のあと、フォルダーを開いても、クイック アクセスと左の一覧に増えないか。
