# v0.12.0（2026-11-20）このアプリ自身の更新（目録から）

淳さんの選択：LAN 上の版からではなく、独自アプリの目録（apps.json）にこのアプリ自身も載せ、GitHub や共有フォルダーの新しい版を起動時に見に行く。

- 起動時（Program Files に入っているときだけ）、scripts\selfupdate_check.ps1（管理者なし）で目録を確かめる。
  exe が ManabitoClassSetup.exe の行を、このアプリ自身とみなす。今より新しい版なら、30 秒の秒読みつきで案内（［今回は更新しない］も可）。
- 更新：scripts\selfupdate.ps1 を一時フォルダーに写して管理者として起動 → 入手 → SHA-256 確認 → ZIP の中から EXE と scripts の並ぶフォルダーを探す →
  「ready」で画面のアプリが閉じる → 閉じるのを待って、新しい版の install.ps1 で入れ替え → エクスプローラー経由で（利用者の権限で）起動し直す。
  入れ替えに失敗しても起動し直す（試験で、ready のあと失敗すると起動し直さない不具合を見つけて直した）。
  起動し直したアプリが update_result.txt を読んで、更新した／できなかったを表示。
- 時間のかかる準備の独自アプリでは、このアプリ自身は SKIP（起動中の自分は入れ替えられない）。
- tools\make_manifest_entry.ps1：ZIP から目録の 1 件分（SHA-256 つき）を作る。
- 検証：版の比べ方（0.11→0.12 で newer、同じ・古いなら none、目録なしなら none）、SHA-256 不一致で ready 前に止まる、ZIP の奥のアプリのフォルダーを見つける、を確認。
