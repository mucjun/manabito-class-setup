# v0.7.0（2026-11-20）トグルと点検の連動・一部異なる

淳さんの要望。

- インストール・アンインストールが終わったら、トグルをその PC の実際の状態にそろえる（入っている＝オン、入っていない＝オフ）。続く点検の判定もこれに従う。
- Office・Adobe の点検の判定を、プロファイルではなくトグルに合わせる。トグルを押すと、一覧と要約がその場で変わる（選んでいた行は保つ）。
  講習用の状態の欄に「入っている（トグル：オン）」のように出す。点検の記録（TSV）はプロファイルを基準にした判定のまま。
- ダウンロード・デスクトップに残っているのが、このアプリのフォルダーだけのときは「違う」ではなく「一部異なる」（黄色い帯）。
  inspect.ps1 に -AppPath を追加（画面のアプリが自分のフォルダーを渡す）。ほかのファイルも残っていれば今までどおり「違う」。
