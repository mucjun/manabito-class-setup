# v0.9.3（2026-11-20）Office の削除に控えの方法

淳さんの試験（v0.9.2）：Office の削除で「署名がありません（UnknownError）」。証明書そのものを読み取れていない（期限切れとは別の原因）。

- 原因を突き止めるため、確かめたファイルの大きさ・先頭の印（実行ファイルなら MZ）・SHA-256、ZIP の中身の一覧を記録に残す。
  署名を読み取れないときは、PowerShell の理由（StatusMessage）も結果に出す。
- 控えの方法を追加：Get Help のツールが使えない（ダウンロード・展開・署名・終了コード）か、使っても消えないときは、
  Office 展開ツール（setup.exe、インストールと同じもの）に <Remove All="TRUE"/> の構成を渡して削除する。手順は 7 まで増える。
- 検証：①Get Help が署名で不合格→展開ツールで削除、②Get Help で削除、③両方失敗（両方の理由を表示）の 3 通りを確認。
