# v0.16.1（2026-11-21）初期値・アイコン・スタートメニュー

淳さんの確認から。

- 独自アプリのトグル（講習の準備タブ）は、初めはオフ（目録があっても自動でオンにしない）。独自アプリは［独自アプリ］タブから入れるのが基本。
- アイコンが見えない（白い紙）件：v0.16.0 の EXE にはアイコンが入っていることを確認（7 つの大きさ）。
  - ショートカット（デスクトップ・まなびとツール・独自アプリ）にアイコンの場所（EXE,0）をはっきり書く。
  - Program Files に入れたあと、Windows のアイコンの一時保存を更新する（ie4uinit.exe -show）。
  - 窓にもアイコンを直接設定（WM_SETICON）。
- スタートメニュー：独自アプリを「まなびとツール」に入れるとき、直下に同じ名前の古いショートカットがあれば消す。
- Program Files 以外で動いているときは、画面の下に「新しい版は確かめていません」と出す。独自アプリのタブの「まなびと講習準備」の行にも書き添える。
