# v0.20.4（2026-11-23）新しいスタートの「最近使用」を出さない

淳さんの報告：v0.20.3 で再起動しても、スタートの「最近使用」に、まなびと講習準備とまなびとバックアップが「最近追加」として残る。

## 原因

教室の PC の Windows（ビルド 26300）では、スタートの「おすすめ」が「最近使用」に名前が変わり、仕組みも変わった。
v0.20.2 の HideRecentlyAddedApps は従来の「おすすめ」向けで、新しい「最近使用」には効かなかった。

## 直したこと

「スタートの『最近使用』」（旧「スタートの『最近追加したアプリ』『よく使うアプリ』」）に、次を加えた。
- HKCU\Software\Microsoft\Windows\CurrentVersion\Start の ShowRecentList=0（新しいスタートの、利用者ごとの「最近追加したアプリを表示する」）
- HKLM と HKCU の Software\Policies\Microsoft\Windows\Explorer の HideRecommendedSection=1（「最近使用」の欄そのものを出さない）
これで「最近使用」の欄は、最近追加したアプリ・最近開いたファイルを含めて、まるごと出なくなる。

## 実機で確かめること（［設定をそろえる］→ 再起動のあと）

- スタートに「最近使用」の欄が出ないか。
- 出る場合：設定 →「個人用設定」→「スタート」に「最近使用」のスイッチがあるか、灰色（変えられない）になっているか。
