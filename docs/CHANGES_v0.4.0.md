# v0.4.0（2026-11-20）履歴を消す・初期設定の整理

淳さんの動作確認（ノート PC・Windows 11 Pro 24H2）を受けて。

- ［履歴を消す］を追加（scripts\clean.ps1、管理者として起動）。
  - 最近使ったファイル（ジャンプリストを含む。クイック アクセスのピン留めは残す）、アドレス欄・実行の履歴、Office・メモ帳の履歴、
    IME の学習・入力履歴・ユーザー辞書（淳さんの指示。使用中のファイルは MoveFileEx で再起動時に削除）、ダウンロード、
    デスクトップ（ショートカット以外）、ごみ箱。
  - このアプリが入っているフォルダー（とその親・中身）は消さない（淳さんの指示）。OneDrive と同期しているフォルダーには手を付けない。
  - Word・Excel・PowerPoint・メモ帳が開いているときは、その項目を消さずに「失敗」として知らせる。
  - 画面を開いた利用者と違う利用者で動いたら中止。
- 画面の解像度は変えない方針（淳さん）。点検は「情報」だけにし、プロファイルの screen を check-only に。
- 「ふたを閉じたとき」：隠し項目の機種で読めなかったため、/q で読めないときは /qh で読む。「そろえる」で電源接続時を「何もしない」に。
- OneDrive の自動起動：書いたあとに読み直し、戻っていたら「失敗」にして値を記録に残す。点検の説明に StartupApproved の値を出す。
- ボタンの名前を「設定をそろえる」に短縮。［履歴を消す］は柿色の枠。
