# v0.11.0（2026-11-20）Program Files に入れる

淳さんの要望。元を消す場所は「ダウンロード・デスクトップ・ドキュメント」（淳さんの指定）。

- Program Files 以外から起動したら、Program Files\Org_Apps\ManabitoClassSetup に入れて（scripts\install.ps1、管理者）、そこから起動し直す。
  EXE・scripts は入れ替え、profiles は上書き（中身が違えば profiles_backup に控え）。デスクトップとスタートメニュー（全員）にショートカット。
- 入っている版のほうが新しければ、入れ替えずにそちらを起動（版は EXE の版情報で比べる）。
- 元の場所の削除：ダウンロード・デスクトップ・ドキュメントの中から起動したときだけ。名前が ManabitoClassSetup で始まるフォルダーならフォルダーごと（同じ名前の zip も）、
  それ以外はアプリのファイルだけ。Program Files 側のアプリが、元のアプリの終了を待ってから消す。Program Files の中は決して消さない。
- ［この場所のまま使う］／ --portable で、入れずに動かせる（開発・試験用）。
- すでに開いているアプリがあるときに別の場所から起動したら、「閉じてから、もう一度起動してください」と知らせる。
- ビルドに version.lib を追加（EXE の版を読むため）。
