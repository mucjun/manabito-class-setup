# v0.20.3（2026-11-23）スタートの「すべて」のビューをカテゴリに

淳さんの要望：このツールで設定するとき、スタートメニューのビューを「カテゴリ」にする。

- ［設定をそろえる］と点検に「スタートの『すべて』のビュー」（プロファイル startAllAppsView、標準 category）。
  HKCU\Software\Microsoft\Windows\CurrentVersion\Start の AllAppsViewMode（0 カテゴリ・1 グリッド・2 一覧。値が無いときはカテゴリ）。
  スタートメニューの部品（StartMenuExperienceHost）が自分の値で上書きすることがあるため、部品を止めてから書く（次にスタートを開くと読み直す）。
- 確かめたこと（この検証環境）：値なし・0 → OK、2（一覧）→ そろっていない、プロファイルで「変えない」→ 対象外。

## 実機で確かめること

- ［設定をそろえる］のあと、スタートを開くと「すべて」が「ビュー：カテゴリ」になっているか。再起動しても戻らないか。
