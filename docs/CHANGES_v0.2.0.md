# v0.2.0（2026-11-20）設定をそろえる

- ［講習用に設定をそろえる］を追加。元に戻せる設定だけを変える（履歴・ファイルは消さない）。
  - スリープ・画面の消灯・休止、背景（無地）、拡張子、ウィジェット、タスクバーの検索、通知、OneDrive の自動起動、音量（消音）、Windows Update。
  - apply.ps1 だけを管理者として起動（UAC）。画面を開いた利用者と違う利用者で動いたら中止。
  - タスクバー・拡張子を変えたときはエクスプローラーを起動し直す。
  - 終わると自動で点検し直し、「そろえました（変えた n・失敗 n）」を点検結果の前に出す。失敗があれば一覧を表示。
- ウィジェットはポリシー（AllowNewsAndInterests=0）で消す。点検もポリシーを見るように変更。
- デスクトップが OneDrive と同期しているときは、点検の説明にその旨を出す（次の「片付け」では対象外にする）。
- 標準・WEB 講座のプロファイル：背景 #1F3A5F、Windows Update は「止める」（淳さん決定）。
- 説明欄のスクロールバーは、入りきらないときだけ出す。
- 「点検版」の表記を外した。
