# v0.5.0（2026-11-20）時間のかかる準備

- 2 段目「時間のかかる準備」を追加（淳さんの要望）。
  - トグル：Office／Adobe CC／独自アプリ。初期値はプロファイル（office・adobe が install、ownAppsManifest があるか）。
  - ［今すぐ実行］［時間を指定して実行］＋時刻（HH:mm、前回の値を settings.ini に保存、過ぎていたら翌日）。
  - 管理者の確認は押したときの 1 回。scripts\deploy.ps1 が管理者として起動し、開始時刻まで待つ（夜中に UAC に答えられないため）。
  - 待機中・作業中はスリープさせない（ES_SYSTEM_REQUIRED＋ES_DISPLAY_REQUIRED。画面側と PowerShell 側の両方）。
  - 電池で動いているときは始めない。
  - 状況を 1 秒ごとに表示（開始までの残り時間、何番目を準備中か）。作業中は［時間を指定して実行］が［取り消す］になる（取り消しはフラグファイル）。
  - 終わると自動で点検し直し、「準備しました（済ませた n・失敗 n）」を出す。
- Office：展開ツールを入手し、Microsoft の署名を確認して /configure（profiles\office.xml：64 ビット・日本語・最新チャネル・Teams/Lync/Groove 除外）。
- Adobe：インストーラーを入手し、Adobe の署名を確認して --silent。入ったことを最大 15 分待って確かめる。
- 独自アプリ：目録（apps.json）→ ZIP → SHA-256 確認 → Org_Apps に展開、前の版は _old。同じ版なら何もしない。起動中なら入れ替えない。
  Linux 上で、新規・同じ版・更新（_old）・SHA-256 不一致の 4 通りを確認済み。
