# v0.20.2（2026-11-23）スタートの「最近追加」をより確実に消す

淳さんの報告：v0.20.1 でも、スタートの「最近使用」に、まなびと講習準備とまなびとバックアップが「最近追加」として出る。

- HideRecentlyAddedApps は、Microsoft の資料で「効かせるには再起動が要る」とされている（explorer.exe の再起動か PC の再起動）。
  自動の更新だけでは［設定をそろえる］は動かないので、更新のあとに［設定をそろえる］と再起動が要る。
- 同じ値を利用者ごと（HKCU\Software\Policies\Microsoft\Windows\Explorer）にも書く。PC 全体だけでは「おすすめ」に残り、利用者ごとに書くと消えた報告があるため。
- 書いたあと、スタートメニュー（StartMenuExperienceHost）を読み込み直す。結果の説明に「再起動のあとに効きます」と出す。

## 実機で確かめること

- ［設定をそろえる］のあと、設定 →「個人用設定」→「スタート」の「最近追加したアプリを表示する」が灰色になるか。
- 再起動のあと、スタートの「最近使用」に、まなびと講習準備・まなびとバックアップが出ないか。
