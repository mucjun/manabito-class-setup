# v0.19.5（2026-11-22）v0.19.4 の実機の記録を受けて

確認できたこと：v0.19.4 への自動の更新、先生用の窓のちらつきが止まったこと。

## 直したこと

- 配布プリンター：入らなかった設定が、閉じても片付かなかった。v0.19.4 は「画面の一覧の最後の点検の行」で判断していたが、
  ［履歴を削除して終了する］で閉じると、一覧が［履歴を消す］の結果に入れ替わってプリンターの行が無くなり、しかも「作業の途中」扱いで消さなかった。
  → ［設定をそろえる］［まとめて実行］の結果のファイルで判断し、失敗した設定の版を printers_failed.txt に覚える（入ったら忘れる）。
    閉じるときはその記録だけを見る。消さないのは、プリンターを入れる作業（設定をそろえる・まとめて実行）の最中だけ。
- 保存されたログイン情報：資格情報が 0 件の PC で、いつも「調べられません」になっていた。
  関数から空の一覧を返すと、PowerShell が $null に変えてしまうため。→ 一覧のまま返す（return ,@(...)）。0 件で「0 件（そろっている）」になることを確認。
- 受け取った授業ファイル：受け取る場所がダウンロード フォルダーそのもののとき、［履歴を消す］で「念のため消していません（失敗）」になっていた。
  → 受け取る場所がダウンロード・デスクトップと同じなら、点検は対象外、消すのはその項目に任せる（失敗にしない）。
- 点検から「PDF を開くアプリ」を外した（淳さんの指定。サインインし直すまで切り替わらず、点検では分かりにくいため。設定は［設定をそろえる］で続ける）。
- 3 つのプロファイルの独自アプリ（ownApps）から、まなびとPDFツールを外した（淳さんの指定）。
  ［設定…］で保存したプロファイルは、保存したときの内容を持っているので、必要なら開き直して保存し直す。

## 加えたもの

- 記録のフォルダーの整理（淳さんの提案）：起動したとき、ファイルが 50 個を超えていたら、古いものから消して新しい 30 個を残す。10 分以内のものは消さない。
