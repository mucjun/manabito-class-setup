# v0.14.0（2026-11-20）前の受講生のサインインを消す・Office の LAN 配布

淳さんの要望：Microsoft・Adobe に加え、受講生が勝手に個人の Google・Apple・AI ツールなどにログインしている可能性も考える。

- 新しい部品 scripts\modules\signout.ps1（点検と［履歴を消す］の両方）：
  Windows に追加されたアカウント（WAM でサインアウト）、Office のサインイン（とライセンス）、Adobe CC のサインイン（opm.db）、
  資格情報マネージャーの汎用資格情報（Windows 資格情報は残す）、ほかのアプリ・ブラウザーのデータ（17 種類）、利用者が入れたアプリ（知らせるだけ）。
- Edge・Chrome は User Data ごと消して初期の状態に（Local State に残るサインインのアカウント名・拡張機能・追加のプロファイルも消える）。
  点検でブラウザーへのサインイン・プロファイル数・拡張機能数を表示。
- プロファイルに browserFullReset・officeRemoveLicenses・signOutApps・keepCredentials を追加（標準・WEB 講座）。
- 確認の文に、消すものと「開発用の PC では実行しない」を追加。
- 検証（偽の痕跡で）：点検で Chrome のサインイン・プロファイル・拡張機能、Adobe、Firefox・Zoom・LINE・ChatGPT・Claude を検出し、［履歴を消す］で全部消えることを確認。

## 実機で確かめること

- Windows に追加されたアカウントのサインアウト（WAM）が、管理者として動いているときにも効くか。
- Office・Adobe が、消したあと本当にサインインを求めるか（ライセンスの扱いを含む）。
- 資格情報マネージャーの件数と、消したあとに困るものがないか。
- Edge を初期化したあとの最初の設定の画面（毎回出る）。

## Office の LAN 配布

淳さんの要望（Adobe CC は個人版で受講生ごとのアカウントのため対象外。Office も受講生ごとのアカウントなので、ライセンスを消す設定のまま）。

- 配布サーバー：［Office のインストール元を用意する］（scripts\office_source.ps1、展開ツールの /download。OfficeSource.new に作ってから入れ替え）。
  UDP の答えに office=版|バイト を足し、TCP に OFFICE（一覧）・OGET（中身）を追加（合言葉なし）。受け取った PC の一覧に「（Office）」として表示。
  授業ファイルを配っていないとき（Office だけ）は、受講生の PC に「配布サーバーがあります」と出さない。
- 受け取る側（deploy.ps1 の Install-Office、手順 6 つ）：展開ツールの入手と署名 → LAN を探す → 受け取る → インストール → 確認。
  受け取った .cab の署名を確かめ、構成に SourcePath と AllowCdnFallback を足して入れる。終わったら受け取ったものを消す。
- 検証（代役のサーバーで）：見つける、3 ファイルを受け取り中身が一致、「..」と「C:\」を含む名前は受け取らず外に書かない
  （その場合は LAN からの受け取りをやめてインターネットから）、普通のサーバーでは成功まで通る。構成ファイルへの SourcePath の書き足し。

## 実機で確かめること（LAN 配布）

- ［Office のインストール元を用意する］で、実際に約 3.4 GB がダウンロードされ、版が表示されるか。
- 別の PC の［今すぐ実行］（Office をオン）で、LAN から受け取ってインストールできるか。有線 LAN と Wi-Fi での時間。
