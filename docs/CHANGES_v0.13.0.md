# v0.13.0（2026-11-20）LAN 内の授業ファイル配布

淳さんの要望と、決めたこと（合言葉あり・ファイアウォールは入れるときに登録・受け取る場所はドキュメント\授業ファイル・履歴を消すで消す・受け取る側はアプリが開いているときだけ）。

- 新しいファイル src\share.h・src\share.cpp（Winsock。新しい DLL は足さない）。ビルドに ws2_32.lib・iphlpapi.lib を追加。
- 配布する側：［配布サーバーになる］（右上）→ ドロップでファイル・フォルダー・ドライブを足す／外す、合言葉 4 桁、受け取った PC の一覧と進み具合。
  パブリックのネットワークなら注意を出す。
- 受け取る側：起動中は 5 秒ごとに LAN を探し（255.255.255.255 と、ネットワークの区切りごとのブロードキャスト）、見つけたら案内 → 合言葉 → フォルダー → 受け取り。
  合言葉を間違えたら聞き直す。取り消し可。受け取りは .part に書いてから入れ替える。
- 守り：受け取るフォルダーの外を指すパスは受け取らない（15 通りの例で確認）。合言葉の総当たりは 5 回で 1 分止める。
- install.ps1：ファイアウォールにこのアプリの受け口を登録（プライベート・ドメイン）。
- 点検と［履歴を消す］に「受け取った授業ファイル」。危ない場所（ドライブの直下・利用者のフォルダーそのもの・Windows・Program Files）は消さない。

## 未確認（実機で）
