# v0.20.13（2026-11-24）そろえたあとの結果と再起動の秒読み

淳さんの要望：［設定をそろえる］の後に確認の画面（OK ○件・NG ○件）と「再起動しますか？」。5 分の秒読み、［いますぐ再起動］［再起動を取りやめる］。何もしないと自動で再起動。

- ［設定をそろえる］［まとめて実行］の後に、結果と再起動の画面（TaskDialog）を出す。OK は DONE と SAME、NG は FAIL（項目名と説明を 8 件まで）、ほかは対象外。
  失敗のときに出していた別のメッセージは、この画面にまとめた。
- 5 分の秒読み（下の欄に残り時間、進み具合の棒）。0 になると［いますぐ再起動］を押したのと同じ。初めの選択（Enter）は［再起動を取りやめる］、×・Esc も取りやめ。
- 再起動は ExitWindowsEx(EWX_REBOOT)（SeShutdownPrivilege を有効にして）。強制はしない（保存していないアプリは Windows が「保存しますか」と聞く）。
- 先生用の窓を開いている PC では秒読みしない（配布などが途中で止まるため）。［いますぐ再起動］を押したときだけ再起動する。
- マニュアル 4-1 の手順と注意を直した。

- ［設定をそろえる］の後に画面が出て、OK・NG の件数が合うか。5 分後に再起動するか。［再起動を取りやめる］で止まるか。
- 先生用の窓を開いた PC では、秒読みが出ないか。
