# v0.13.1（2026-11-20）配布サーバーになるときにプライベートへ切り替え

淳さんの要望。淳さんの PC で、管理者の PowerShell から Set-NetConnectionProfile で Public → Private に切り替えられることを確認済み。

- ［配布サーバーになる］を押したとき、つながっているネットワークに「パブリック」があれば、名前を出して
  ［プライベートに切り替えて始める（おすすめ）］［このまま始める］を聞く。公共の Wi-Fi では切り替えないよう注意書き。
- 切り替えは scripts\network_private.ps1（管理者）。今つながっていてパブリックのものだけをプライベートにする。
- 配布用の窓のボタンを［ネットワークの設定を開く］から［プライベートに切り替える］に変更。
- 受け取る側は切り替えない（自分から呼びかけ、自分からつなぎに行くため、パブリックのままでファイアウォールに止められない）。
- ネットワーク名を読むため、ビルドに oleaut32.lib を追加。
