# v0.16.0（2026-11-21）タブ・独自アプリ・アイコン・Windows Update の警告

淳さんの要望（実機の試験のあと）。まなびとバックアップは、配布サーバーで setup.exe を配る今の仕組みで進める（トークンを公開のアプリに入れないため）。

- 画面をタブに分けた：［講習の準備］［独自アプリ］。
- 独自アプリのタブ：目録のアプリを 1 行ずつ（チェック・名前・入っている版・最新・状態・［セットアップ］）。
  ［チェックしたものをまとめてセットアップ］［一覧を読み直す］。進み具合は同じタブに作業ごとの行で表示。
  scripts\apps_status.ps1（一覧と版の比較）、deploy.ps1 に -OnlyApps（選んだアプリだけ）。
  このアプリ自身を選んだときは、ほかを入れ終えてから自分の更新（selfupdate）を始める。
- スタートメニュー（全員）に「まなびとツール」グループ。独自アプリ（Install-OneApp、同じ版でもそろえる）とこのアプリ（install.ps1）を入れる。
  v0.15 までの「まなびと講習準備」（スタートメニューの直下）は消す。
- アイコン（res\app.ico、16〜256）：紺の角丸に白い画面と柿色のチェック。16・24 はチェックだけ。配布サーバーなどの窓にも。見本は docs\icon_preview.png。
- Windows Update：起動時に裏で確かめ（scripts\wu_check.ps1）、点検に表示。［設定をそろえる］［まとめて実行］の前に、今日の確認でまだ入っていない更新があれば知らせる。
- 点検に Defender の定義の古さ、［設定をそろえる］に「更新の LAN での分け合い」（DODownloadMode=1）。
- 検証：apps_status（最新・新しい版あり・入っていない、このアプリ自身の比較）、Windows Update の結果の読み取り、MinGW ビルド（警告なし）。

## 実機で確かめること

- タブの切り替え、独自アプリのタブの見え方（1366×768 でも収まるか）、チェックボックスの背景。
- 独自アプリのタブから、このアプリ自身の更新（v0.16.0 → 次の版）。
- Windows Update の確認が実際に何分かかるか、件数が設定アプリの表示と合うか。
- スタートメニューの「まなびとツール」グループ。
