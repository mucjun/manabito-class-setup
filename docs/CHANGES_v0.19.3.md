# v0.19.3（2026-11-22）先生用の窓のちらつきを止める

淳さんの報告：受講生の PC の様子を見ているとき、頻繁に書き直されて画面がちらつく。

## 原因

- ［教室の PC］の一覧を、中身が変わっていなくても 0.5 秒ごとにすべての行・列を書き直していた。
- 上の集計の文のために、窓全体を 0.5 秒ごとに描き直していた。窓に WS_CLIPCHILDREN が無く、描き直しのときに一覧の上も塗っていた。
- 画面に直接描いていて、背景を塗ってから文字を書く途中の状態が見えていた。

## 直したこと

- 報告が届くたびに「変わった印」（g_reportsVersion）を増やし、印が変わったときだけ一覧を作り直す（報告が無くても「応答なし」に変わるので、10 秒ごとにも確かめる）。
- 一覧のセルは、前と違うときだけ書き換える（SetCellText）。行の数は足りない分・多い分だけを足し引きする（EnsureRowCount）。色分けの状態も変わったときだけ。
- 集計の文は、変わったときに、その行だけを描き直す。［配る］タブの受け取り済みの台数も同じ。
- 窓に WS_CLIPCHILDREN。WM_PAINT は裏の画用紙に描いてから一度に写す（ダブルバッファ）。
- ［配る］タブの「受け取った PC」、［プリンター］タブの「教室の PC の様子」も、変わったところだけ書き換える（前は 3 秒ごとに全部消して作り直していた）。
- 本体の窓は、もともとダブルバッファと WS_CLIPCHILDREN があり、変えていない。
