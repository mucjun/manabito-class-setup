# v0.20.12（2026-11-24）Adobe CC の起動時の動きを講座ごとに

淳さんの要望：WEB系のコースでは、Adobe CC が自動で立ち上がってもかまわない。

- プロファイルの adobeStartup：off（動かさない。基準・事務系）／on（動かす。WEB系）／それ以外（変えない）。
- on のときは、前に「動かさない」にしたもの（StartupApproved が奇数で始まるもの）を 02 で始まる 12 バイト（タスク マネージャーの「有効」と同じ）に戻し、
  Adobe Update Service を「自動」に戻す。事務系 → WEB系に切り替えても、［設定をそろえる］で自動で立ち上がる状態になる。
- 項目の名前を「Adobe CC の起動時の動き」に。マニュアル 7 章の一言も直した。
- 確かめたこと（この検証環境）：事務系で止めた後に WEB系 → そろっていない（止めている）、同じ状態で事務系 → そろっている、戻した後に WEB系 → そろっている。
