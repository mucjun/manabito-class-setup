# v0.20.5（2026-11-23）スタートの「新着順」（最近使用）の欄のスイッチをオフに

淳さんの確認（写真）：設定 →「個人用設定」→「スタート」で、「最近追加したアプリを表示する」は灰色でオフ（v0.20.2 のポリシーが効いている）だが、
親の「新着順」（英語版 Recent。旧「おすすめ」）のスイッチがオンのままで、欄が出ていた。手でオフにすると消える。HideRecommendedSection（v0.20.4）は、この PC ではスイッチが灰色になっていない。

- 「スタートの『最近使用』」に、HKCU\Software\Microsoft\Windows\CurrentVersion\Start の ShowRecentSection=0（「新着順」の欄のスイッチ。手でオフにしたのと同じ）を加えた。
- スタートメニューの部品は自分の覚えている値で上書きすることがあるため、この項目は部品を止めてから書く（書いたあとも読み込み直す）。
