# v0.9.1（2026-11-20）二重に動かさない

淳さんの試験で、v0.6.0 のアプリが起動したまま残り、準備の作業が 2 つ同時に走った可能性があった（Office の削除・Adobe のインストールが失敗）。
［履歴を消す］では、v0.6.0 の EXE が起動中のため消せなかった（アクセスが拒否されました）。

- アプリを 2 つ同時に起動しない。2 つ目は、開いている窓を前に出して終わる。
- そろえる・履歴を消す・時間のかかる準備が同時に走らないよう、PC 全体の順番待ち（名前付きミューテックス）を追加。
  そろえる・履歴を消すは、ほかの作業中なら「別の作業が動いている」と知らせて止まる。
  時間のかかる準備は、開始時刻になってから順番を取り、ほかの作業が終わるのを最大 30 分待つ（開始待ちの間はほかの作業を止めない）。
- ［履歴を消す］で、別の場所の講習準備アプリが起動したままのときは、その場所と「閉じてからもう一度」を知らせる。
- 検証：別プロセスから同じ順番待ちを取れないことを確認。
